# 百草园

开源的中文植物与真菌知识库。面向户外探险和乡居生活：认得出，知道能不能吃、怎么处理、怎么种。

- 名称、别名、地方名
- 形态特征、图片
- 地域分布、生境
- 各部位的用途与处理方法
- 毒性、中毒类型、易混淆物种
- 栽培方法
